# 찻잎상회 결제 화면 (예시 프로젝트)

처음 구매하는 손님이 휴대폰으로 차 두 봉지를 결제하는 정적 HTML 화면입니다. 이 폴더는 cogux 스킬의 예시 입력입니다.

- 사용자 진술: 고객 문의의 대부분이 "처음인데 결제해도 안전한가요?"와 "휴대폰 번호를 어떻게 적나요?"입니다.
- 주요 과업: 배송지를 적고 결제 수단을 골라 34,000원을 결제한 뒤 주문 접수를 확인합니다.
- 제약: 백엔드 없는 단일 HTML, 모바일 우선, 브랜드 색은 초록 계열.
- `index.before.html`은 원본이고 `index.html`은 cogux를 적용한 결과입니다.
