## 2. 선택한 원칙

| 원칙 | 근거 | 적용 이유 |
|---|---|---|
| `cognitive-load` | U1, S1 | 위젯 9개와 배너가 한꺼번에 보이면 시작 전에 지칩니다. 지금 필요한 것만 남깁니다. |
| `von-restorff-effect` | U2, S1 | 같은 모양 버튼 4개 때문에 무엇을 눌러야 할지 모릅니다. 주요 행동 하나만 두드러지게 합니다. |
| `zeigarnik-effect` | U3, T1 | 끊긴 곳이 표시되면 돌아오기 쉽습니다. 이어 할 지점을 첫 화면에 둡니다. |
| `flow` | U1, S1 | 세션 중에는 알림과 배너가 집중을 깨므로 세션 화면에서 모두 뺍니다. |
| `progressive-disclosure` | S1, U1 | 통계, 설정, 달력은 필요할 때만 열립니다. 접어 둡니다. |
| `serial-task-switching` | U3 | 끊김이 잦으니 중단 지점을 저장하고 보여 주는 설계가 필요합니다. |
| `parkinsons-law` | U2, T1 | 시작 문턱을 낮추려고 기본 길이를 10분으로 정해 시작합니다. |
| `peak-end-rule` | T1 | 마친 뒤 한 일을 보여 주는 마지막 화면이 기억을 결정합니다. |

## 3. 제외한 원칙

| 원칙 | 제외 이유 |
|---|---|
| `goal-gradient-effect` | 연속 기록과 진척 압박은 운영자가 금지한 방향이고(C1), 쉬면 자책하게 만들 수 있습니다. |
| `loss-aversion` | 기록이 사라진다는 문구가 원본 문제 자체입니다. 사용하지 않고 제거합니다. |
| `hicks-law` | 선택지를 줄이는 일은 인지 부하와 점진적 공개가 이미 다룹니다. 중복이라 따로 두지 않습니다. |
| `postels-law` | 입력 폼이 거의 없는 화면입니다. |
| `social-proof` | 친구 순위는 비교 압박이 되므로 이 사용자에게 맞지 않습니다. |

## 4. 설계 결정

| 원칙 | 화면 | 변경 | 관찰 확인 |
|---|---|---|---|
| `cognitive-load` | 홈 | 위젯 9개를 접힘 영역 2개로 줄이고 배너를 제거 | 홈에서 배너 0개, 접힘 영역은 기본으로 닫힘 |
| `von-restorff-effect` | 홈 | 주요 행동 하나만 강조 | 홈에서 보이는 강조 버튼이 1개 |
| `zeigarnik-effect` | 홈 | 어디까지 했는지와 멈춘 시각 표시 | 이어 할 지점 문구가 첫 화면에 있음 |
| `flow` | 세션 | 세션 화면에서 알림·배너 제거 | 세션 화면에 알림 요소 0개 |
| `progressive-disclosure` | 홈 | 통계·설정은 접어 둠 | 열린 접힘 영역 0개 |
| `serial-task-switching` | 세션 | 지금 할 일 한 줄을 화면에 고정 | 세션 화면에 "지금 할 일" 문구가 있음 |
| `parkinsons-law` | 세션 | 10분 시작 버튼과 타이머 | 버튼 문구와 타이머 초기값이 10분 |
| `peak-end-rule` | 종료 | 한 일, 다음에 이어 할 곳을 3줄로 | 종료 화면 목록 3개 |

## 5. 구현

수정한 파일은 `index.html` 하나입니다(원본은 `index.before.html`로 보존). 테마 전환은 이 저장소용으로 직접 쓴 해·달 스위치입니다. 이어 할 지점 문구는 정적 문자열이며, 저장 기능은 구현하지 않았습니다. 이 점은 미확인 항목에 적었습니다.

## 6. 검증 결과

검증은 agent-browser 헤드리스 세션으로 폭 375px에서 실행했습니다.

| 관찰 확인 | 결과 |
|---|---|
| 홈 배너 0개 | 통과: 0개 (원본 2개) |
| 보이는 강조 버튼 1개 | 통과: 1개 (원본 버튼 4개 동급) |
| 접힘 영역 기본 닫힘 | 통과: 열린 영역 0개 (원본 위젯 9개 노출) |
| 이어 할 지점 문구 | 통과: "수학 · 이차함수 · 7번 문제까지 했습니다. 어제 18:40에 멈췄습니다." |
| 세션 화면 알림 0개 | 통과: 0개 |
| 지금 할 일 문구 | 통과 |
| 10분 타이머 | 통과: 초기값 10:00 |
| 종료 화면 3줄 | 통과: 3개 |
| 가로 넘침 없음(375px) | 통과 |
| 버튼 높이 | 통과: 48px (원본 30px) |

## 7. 미확인 항목

- 이어 할 지점은 고정 문구이고 실제 저장과 복원은 없습니다. 중단 후 복귀를 실제로 지원하는지는 확인하지 않았습니다.
- 타이머가 0이 될 때의 종료 동작은 실행하지 않았습니다.
- 키보드 조작, 200% 확대, 320px과 768px, 색 대비, 모션 감소 설정은 확인하지 않았습니다.
- 사용자를 대상으로 한 시험은 하지 않았습니다.
