# 집중공부 앱 홈 화면 (예시 프로젝트)

ADHD가 있는 학습자가 공부를 시작하고 중단된 세션에 돌아오는 정적 HTML 화면입니다. 이 폴더는 cogux 스킬의 예시 입력입니다.

- 사용자 진술: 사용자는 ADHD가 있는 중고등·성인 학습자입니다. "앱을 열면 뭘 눌러야 할지 몰라 닫아 버립니다", "중간에 끊기면 어디까지 했는지 모릅니다."
- 주요 과업: 공부를 바로 시작하거나 어제 끊긴 곳에서 이어 하고, 끝나면 한 일을 확인합니다.
- 제약: 백엔드 없는 단일 HTML, 자책감을 주는 연속 기록 압박 금지(운영자 요청).
- `index.before.html`은 원본이고 `index.html`은 cogux를 적용한 결과입니다.
