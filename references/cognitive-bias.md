# Cognitive Bias (인지 편향)

- **id:** cognitive-bias
- **분류:** 결정
- **정의:** 판단이 일정한 방향으로 어긋나는 여러 경향을 묶어 부르는 말입니다. 사용자와 함께, 화면을 설계하고 조사 결과를 읽는 팀도 점검 대상입니다.
- **출처:** https://lawsofux.com/cognitive-bias/
- **읽은 범위:** 정의, 요점, 유래를 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다. 원 연구는 읽지 않았습니다.
- **적용할 때:** 가격 표시, 기본값, 추천 순서처럼 선택을 유도하는 요소를 정할 때, 그리고 사용자 조사 결과를 해석할 때.
- **적용하지 않을 때:** 편향을 이용해 사용자가 원치 않는 결정을 하게 만드는 용도. 그것은 이 원칙의 적용이 아니라 오용입니다.
- **관찰 확인:** 유도 요소(기본 선택, 강조, 순서)마다 사용자에게 불리한 결과가 없는지, 해제 경로가 같은 화면에 있는지 확인합니다.
