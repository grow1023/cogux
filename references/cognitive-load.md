# Cognitive Load (인지 부하)

- **id:** cognitive-load
- **분류:** 기억
- **정의:** 과업을 끝내려고 사용자가 치러야 하는 생각의 비용입니다. 설계에서는 과업 자체에서 오는 부담과 화면 구성이 더한 부담을 나누어 보고, 뒤의 것부터 줄입니다.
- **출처:** https://lawsofux.com/cognitive-load/
- **읽은 범위:** 정의, 요점, 유래를 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다. 원 연구는 읽지 않았습니다.
- **적용할 때:** 정보가 많은 화면, 전문 용어가 많은 도구, 집중이 어려운 사용자(예: ADHD)를 대상으로 할 때.
- **적용하지 않을 때:** 과업 자체가 본래 복잡한 전문가 도구에서 정보를 무작정 덜어내는 경우. 필요한 정보를 숨기면 부하가 오히려 늘 수 있습니다.
- **관찰 확인:** 한 화면에서 동시에 요구하는 결정·입력·읽기의 수를 세고, 과업과 무관한 요소를 제거한 목록을 기록합니다.
