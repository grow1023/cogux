# Default Bias (기본값 편향)

- **id:** default-bias
- **분류:** 결정
- **정의:** 미리 정해 둔 값이 있으면 사용자가 바꾸지 않고 지나가기 쉬운 경향입니다. 그러므로 기본값은 설계자가 사용자 대신 내리는 결정으로 다룹니다.
- **출처:** https://www.nngroup.com/videos/the-danger-of-defaults/
- **읽은 범위:** 대조함. 영상 페이지의 요약 글만 읽었고 영상은 보지 않았습니다. 정의 문장은 2026-11-27에 새로 썼습니다.
- **적용할 때:** 설정 화면, 옵션 선택, 알림 설정.
- **적용하지 않을 때:** 기본값이 사용자에게 불리한 경우. 이때는 기본값이 아니라 명시적 선택을 요구해야 합니다.
- **관찰 확인:** 기본값이 사용자에게 유리하거나 중립인지, 바꾸는 방법이 같은 화면에 있는지 확인합니다.
