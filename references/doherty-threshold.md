# Doherty Threshold (도허티 임계)

- **id:** doherty-threshold
- **분류:** 시간·동기
- **정의:** 입력과 화면 반응 사이의 지연을 설계 대상으로 삼는 기준입니다. 이 항목의 출처는 400ms를 경계값으로 제시합니다. 제품의 실제 지연은 측정해서 확인합니다.
- **출처:** https://lawsofux.com/doherty-threshold/
- **읽은 범위:** 정의, 요점, 유래를 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다. 원 연구는 읽지 않았습니다.
- **적용할 때:** 저장, 필터, 전환, 입력 피드백처럼 사용자가 반응을 기다리는 모든 상호작용.
- **적용하지 않을 때:** 본래 오래 걸리는 작업(업로드, 분석). 이때는 반응 속도 대신, 요청이 접수되었고 어디까지 처리되었는지 알리는 것을 목표로 삼습니다.
- **관찰 확인:** 주요 상호작용 3가지에 대해 입력부터 화면 반응까지 시간을 측정하거나, 즉시 반응이 없으면 진행 표시가 뜨는지 확인합니다.
