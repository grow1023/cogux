# Goal-Gradient Effect (목표 접근 효과)

- **id:** goal-gradient-effect
- **분류:** 시간·동기
- **정의:** 남은 거리를 어떻게 느끼는지가 끝까지 가려는 힘을 바꾸는 경향이며, 끝이 가까울수록 힘이 커집니다. 그래서 여러 단계 흐름에서는 사용자가 현재 위치를 알게 되는 방식을 설계합니다.
- **출처:** https://lawsofux.com/goal-gradient-effect/
- **읽은 범위:** 정의, 요점, 유래를 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다. 원 연구는 읽지 않았습니다.
- **적용할 때:** 여러 단계 폼, 온보딩, 학습 진도, 프로필 완성도처럼 끝이 있는 흐름.
- **적용하지 않을 때:** 끝이 없거나 진척을 정직하게 보여줄 수 없는 흐름. 거짓 진척을 만들어 붙잡는 용도는 쓰지 않습니다.
- **관찰 확인:** 진행 표시가 실제 남은 단계와 일치하는지, 첫 단계에서 이미 일부 진척이 보이는지 확인합니다.
