# Loss Aversion (손실 회피)

- **id:** loss-aversion
- **분류:** 감정·평가
- **정의:** 사람이 득과 실을 대칭으로 계산하지 않는다는 관찰입니다. 크기가 같아도 잃는 쪽에 더 큰 무게를 두기 때문에, 무엇을 손실로 표현하는지가 선택에 영향을 줍니다.
- **출처:** https://www.nngroup.com/articles/prospect-theory/
- **읽은 범위:** 대조함. 요약과 전망 이론·손실 회피 설명을 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다.
- **적용할 때:** 되돌릴 수 없는 삭제 확인, 데이터 보존 안내처럼 실제 손실을 알릴 때.
- **적용하지 않을 때:** 가짜 긴급성이나 불안을 만들어 전환을 올리는 용도. 이 스킬은 그런 용도로 쓰지 않습니다.
- **관찰 확인:** 손실을 강조하는 문구가 실제 결과와 일치하는지, 과장된 기한이 없는지 확인합니다.
