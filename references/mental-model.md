# Mental Model (멘탈 모델)

- **id:** mental-model
- **분류:** 학습·모델
- **정의:** 사용자가 "이것은 이렇게 돌아가겠지" 하고 갖고 들어오는 설명입니다. 시스템의 실제 구조와 다를 수 있으므로, 설계 전에 사용자의 말과 행동에서 확인합니다.
- **출처:** https://lawsofux.com/mental-model/
- **읽은 범위:** 정의, 요점, 유래를 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다. 원 연구는 읽지 않았습니다.
- **적용할 때:** 새 기능, 용어 선택, 리디자인, 개념이 낯선 AI·자동화 기능.
- **적용하지 않을 때:** 사용자 조사 없이 설계자의 모형을 사용자의 것으로 단정하는 경우. 모형은 조사나 사용자 진술로 확인해야 합니다.
- **관찰 확인:** 핵심 용어와 동작이 사용자 진술이나 조사 기록의 표현과 일치하는지 대조한 표를 기록합니다.
