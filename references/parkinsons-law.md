# Parkinson's Law (파킨슨의 법칙)

- **id:** parkinsons-law
- **분류:** 시간·동기
- **정의:** 시간에 여유가 있을수록 일이 길어진다는 관찰입니다. 화면 설계에서는 사용자가 예상한 시간보다 흐름이 늘어지는 지점을 찾는 데 씁니다.
- **출처:** https://lawsofux.com/parkinsons-law/
- **읽은 범위:** 정의, 요점, 유래를 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다. 원 연구는 읽지 않았습니다.
- **적용할 때:** 자동 채우기, 기본값, 짧은 제한 시간이 있는 입력 폼.
- **적용하지 않을 때:** 숙고가 필요한 중요한 결정에 인위적인 짧은 제한을 거는 경우.
- **관찰 확인:** 반복 입력 항목에서 자동 채우기나 기본값이 있어서 입력 단계 수가 줄었는지 기록합니다.
