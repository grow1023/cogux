# Peak-End Rule (정점-종결 법칙)

- **id:** peak-end-rule
- **분류:** 감정·평가
- **정의:** 지나간 경험에 대한 평가가 감정이 가장 컸던 대목과 마무리 쪽으로 치우치는 경향입니다. 설계자는 흐름에서 이 두 지점이 어디인지부터 특정합니다.
- **출처:** https://lawsofux.com/peak-end-rule/
- **읽은 범위:** 정의, 요점, 유래를 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다. 원 연구는 읽지 않았습니다.
- **적용할 때:** 결제 완료, 가입 완료, 오류 복구, 학습 세션 종료처럼 끝나는 화면.
- **적용하지 않을 때:** 경험 중간의 막힘을 마지막 화면 장식으로 가리려는 경우.
- **관찰 확인:** 흐름의 마지막 화면이 결과, 다음 행동, 정서적 마무리를 포함하는지, 가장 불편한 지점에 완화 장치가 있는지 확인합니다.
