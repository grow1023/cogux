# Serial Task Switching (순차 과업 전환)

- **id:** serial-task-switching
- **분류:** 시간·동기
- **정의:** 여러 일을 한꺼번에 하는 듯 보여도 주의는 일 사이를 번갈아 옮겨 다닙니다. 옮길 때마다 맥락을 다시 잡아야 하므로, 설계에서는 돌아온 사용자가 맥락을 되찾는 비용을 줄입니다.
- **출처:** https://www.nngroup.com/articles/serial-task-switching/
- **읽은 범위:** 요약과 도입부만 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다.
- **적용할 때:** 여러 탭·창·알림이 있는 도구, 다단계 작업, 중단이 잦은 환경.
- **적용하지 않을 때:** 단일 과업만 있는 짧은 흐름.
- **관찰 확인:** 다른 화면으로 갔다가 돌아왔을 때 입력 중이던 값과 위치가 보존되는지 확인합니다.
