# Sludge Reduction (결정 찌꺼기 줄이기)

- **id:** sludge-reduction
- **분류:** 결정
- **정의:** 선택이나 신청을 끝내려는 사람 앞에 쌓여 진행을 막는 마찰과 혼란을 찾아 걷어 내는 접근입니다. 설득 장치를 더하기 전에, 사용자가 이미 하려던 결정을 방해하는 것부터 봅니다.
- **출처:** https://www.nngroup.com/articles/sludge-decisions/
- **읽은 범위:** 요약과 도입부만 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다.
- **적용할 때:** 가입, 구독 해지, 요금제 선택, 설정처럼 결정이 이어지는 흐름.
- **적용하지 않을 때:** 필요한 확인 절차(되돌릴 수 없는 삭제 확인)까지 없애는 경우.
- **관찰 확인:** 결정 흐름의 단계 수와 불필요한 입력·확인을 센 목록을 기록하고, 줄인 항목이 있는지 확인합니다.
