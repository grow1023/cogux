# Visibility of System Status (시스템 상태의 가시성)

- **id:** visibility-of-system-status
- **분류:** 시간·동기
- **정의:** "지금 어떻게 되고 있습니까?"라는 사용자의 물음에 화면이 늦지 않게 답해야 한다는 원칙입니다. 앞선 조작의 결과를 알아야 다음 행동을 고를 수 있기 때문입니다.
- **출처:** https://www.nngroup.com/articles/ten-usability-heuristics/
- **읽은 범위:** 정의와 핵심 요점의 앞부분을 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다.
- **적용할 때:** 저장, 로딩, 전송, 진행, 오류 후의 모든 상호작용.
- **적용하지 않을 때:** 상태 알림이 잦아 주의를 흩는 경우. 중요한 상태만 알립니다.
- **관찰 확인:** 동작 직후 상태 변화(저장됨, 전송 중, 실패)가 화면에 나타나는지 각 주요 동작마다 확인합니다.
