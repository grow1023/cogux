# Von Restorff Effect (고립 효과)

- **id:** von-restorff-effect
- **분류:** 지각·평가
- **정의:** 강조의 힘이 주변과의 차이에서 나온다는 점을 보여 주는 기억 현상입니다. 둘레의 항목이 서로 비슷할 때 혼자 다른 하나가 기억에서 유리합니다.
- **출처:** https://lawsofux.com/von-restorff-effect/
- **읽은 범위:** 정의, 요점, 유래를 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다. 원 연구는 읽지 않았습니다.
- **적용할 때:** 주요 행동 버튼, 추천 항목, 핵심 경고처럼 하나만 눈에 띄어야 할 때.
- **적용하지 않을 때:** 강조 요소가 여러 개인 경우. 모든 것이 강조되면 아무것도 두드러지지 않습니다.
- **관찰 확인:** 한 화면에서 시각적으로 가장 강한 주요 행동이 하나뿐인지 확인합니다.
