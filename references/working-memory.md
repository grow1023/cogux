# Working Memory (작업 기억)

- **id:** working-memory
- **분류:** 기억
- **정의:** 화면을 넘기거나 값을 견주는 사이에 사용자가 잠깐 머릿속에 들고 있어야 하는 정보가 거치는 자리입니다. 양과 지속 시간에 한계가 있으므로, 화면이 대신 보여 줄 수 있는 것은 외우게 하지 않습니다.
- **출처:** https://lawsofux.com/working-memory/
- **읽은 범위:** 정의, 요점, 유래를 읽었습니다. 정의 문장은 2026-11-27에 새로 썼습니다. 원 연구는 읽지 않았습니다.
- **적용할 때:** 여러 화면을 오가며 값을 비교하거나 이전 정보를 입력해야 하는 흐름.
- **적용하지 않을 때:** 정보가 본래 한 화면에 모두 있는 단순 과업.
- **관찰 확인:** 사용자가 이전에 본 값을 다시 입력하거나 비교해야 하는 곳에서 그 값이 화면에 함께 보이는지 확인합니다.
